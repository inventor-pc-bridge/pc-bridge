# Inventor Mobile Bridge

Download and setup page for **Inventor Mobile Bridge**, the free Windows program that lets the Inventor Mobile Android app control Autodesk Inventor on your PC.

- Site: https://inventor-pc-bridge.github.io/pc-bridge/
- Latest installer: https://github.com/inventor-pc-bridge/pc-bridge/releases/latest/download/InventorMobileBridge.msi
- Privacy policy: https://inventor-pc-bridge.github.io/pc-bridge/privacy.html

This repository holds only the download site (`index.html`, `privacy.html`) and the release installers. The program's source code is not in this repository.

Releases are tagged `v<major>.<minor>.<patch>` and carry one asset, `InventorMobileBridge.msi`.
