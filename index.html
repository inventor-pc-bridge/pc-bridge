Inventor Mobile Bridge

The free Windows companion for the Inventor Mobile app. The app on your phone cannot work without it.

What the bridge is and why it is needed

Inventor Mobile lets you model in Autodesk Inventor from an Android phone or tablet. Autodesk Inventor runs on your Windows PC, and it does the modeling. The phone draws the model, takes your touch and voice commands, and sends each change to the PC.

The bridge is the small program that runs on the PC next to Inventor. It carries the phone's commands out in Inventor through Inventor's own programming interface, and sends the updated model back to the phone. It runs in the notification area by the clock and has no console window.

The bridge listens only on your own private network: a VPN you run or the home network you choose. It does not listen on public addresses, and nothing goes through any cloud service.

What you need

  • Windows 10 or 11, 64-bit. The bridge needs no separate .NET install.
  • Autodesk Inventor 2027 installed and licensed on that PC. Inventor 2027.1 is the tested version. Other versions are attempted: older ones with a warning, newer ones with a note in the bridge log.
  • A private network between the phone and the PC: a VPN that both devices can reach (WireGuard, Tailscale, ZeroTier, OpenVPN, a company VPN, ...), or the same home network with the phone on the PC's Wi-Fi or LAN.
  • The Inventor Mobile app on Android 8 or newer, from Google Play. The app needs bridge 0.9.0 or newer.

Download

Download InventorMobileBridge.msi

This always downloads the latest version. All versions and their notes are on the releases page.

Install

  1. Run InventorMobileBridge.msi from your Downloads folder and follow the installer. You may be asked for administrator approval.
  2. At the end, the bridge starts and its window opens. Keep it open for the next step, or open it later from the Start Menu entry Inventor Mobile Bridge.

Windows may warn you the first time. Because this installer is not yet signed with a certificate that Windows trusts, you may see "Windows protected your PC" (SmartScreen) or a publisher shown as "Unknown publisher".

To continue, click More info, then Run anyway. The file is the same one published here; the warning appears because the publisher certificate is not from a public certificate authority yet.

If you are not comfortable running it, do not install it. Ask the person who gave you the app.

Pair your phone

Pairing links one phone or tablet to this PC. You do it once per device.

  1. On the PC, open the bridge window. It shows the PC address (one or more addresses), the port (47800) and the pairing code (five groups of four characters). Use Show and Copy to read or copy the code.
  2. Choose the network. In the bridge window, pick VPN (the default) or Home network. Use Home network only on a network you trust, because it is not encrypted.
  3. On the phone, open the Inventor Mobile app, and on the "Set up your PC" screen (or the connection panel) enter the PC address or addresses, separated by commas, for example 192.168.1.20, 10.8.0.2. Enter the port 47800 and the pairing code.
  4. Tap Connect. The app shows "Connected" with the Inventor version when it is paired. The app uses whichever address answers, so it works at home and away.

The pairing code is for pairing only. Keep it private: anyone with the code and network access to this PC can pair a device. Press New code in the bridge window to replace it. Devices already paired keep working.

Each paired phone or tablet gets its own hidden Inventor, started by the bridge and kept running while the bridge runs. Inventor you open yourself on the PC is never used by the phone.

Updates

Once a day the bridge checks the latest release on this site's GitHub repository and offers to download and install a newer version. The check uses an outgoing HTTPS connection only. Nothing from your phone, your files or your models is sent.

You can turn the daily check off in the bridge window. You can always install an update yourself from the download button above; installing a newer version keeps your paired devices and settings.

Troubleshooting

If the app says it cannot connect or the pairing code is not accepted, check these in order:

  1. Network: is the VPN switched on on the phone, or is the phone on the same Wi-Fi as the PC, with Home network chosen in the bridge window?
  2. PC bridge: is Inventor Mobile Bridge running on the PC? Its icon is by the clock. If it is not, open it from the Start Menu.
  3. Pairing code: does it match the code in the bridge window? Dashes and capitals do not matter.

If the phone says Inventor is not running, tap the connection message in the app (or say "start Inventor") to start it on the PC. The first start can take about a minute.
